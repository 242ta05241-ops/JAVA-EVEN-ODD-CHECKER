# Even or Odd Number Checker in Java

## Description
This Java program checks whether a given number is even or odd using the ternary operator. It accepts user input through the Scanner class and displays the result.

## Features
- Accepts user input using the Scanner class.
- Checks whether the number is even or odd.
- Uses the ternary operator for decision making.
- Simple and beginner-friendly Java program.

## Technologies Used
- Java
- Scanner Class
- Ternary Operator

## Program Logic
1. Read a number from the user.
2. Check if the number is divisible by 2.
3. Display "It is Even" if the remainder is 0; otherwise display "It is Odd".

## Sample Output

### Input

Enter a number:
10


### Output

10 it is even


### Input

Enter a number:
7


### Output

7 it is odd
